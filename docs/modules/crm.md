# Módulo CRM

## Objetivo

Centralizar gerenciamento de leads, corretores, clientes e acompanhamento comercial.

## Responsabilidades esperadas

- gerenciamento de leads;
- atribuição de corretor;
- acompanhamento comercial;
- histórico de interações;
- status do lead;
- filtros e buscas;
- dashboards futuros.

## Entidades relacionadas

- usuário;
- corretor;
- lead;
- imóvel;
- cliente.

## Regras importantes

- Admin pode visualizar todos os leads.
- Corretor visualiza apenas seus leads.
- Alterações críticas devem ser registradas futuramente.
- O backend deve validar acesso aos dados.

## Possíveis evoluções futuras

- automações;
- SLA de atendimento;
- distribuição automática de leads;
- integração WhatsApp;
- integração email;
- funil de vendas;
- analytics.
